# 安装与使用

[返回首页](../README.md) · [English](USAGE.en.md)

## 安装与更新

使用 Chrome 116 或更高版本。从 [Releases](https://github.com/utiwaaaaaien/webpage-conversion-helper/releases/latest) 下载 Chrome ZIP，解压到固定文件夹。在 `chrome://extensions` 开启开发者模式，点击「加载已解压的扩展程序」，选择其中直接包含 `manifest.json` 的 `extension` 文件夹。此流程参照 [Chrome 官方安装说明](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)。

首次使用可在扩展程序菜单将「网页转换助手」固定到工具栏。组织管理的浏览器可能限制开发者模式，请向管理员确认。删除或移动安装目录会影响已安装扩展。

更新时先备份原目录，再将新 `extension` 文件夹内的内容替换到原安装目录。在扩展程序页面点击「重新加载」，刷新原网页后重新打开插件。卸载通过 Chrome 扩展程序页面的「移除」完成；已导出文件需另行删除。

## 加载与保存

1. 打开普通 HTTP/HTTPS 网页，完成网站登录并手动展开需要保存的内容。
2. 点击工具栏图标，再点击「加载全部网页」。这一步可选；已有内容足够时可直接保存。
3. 等待完成或点击「停止加载」，查看图片数量与提示，再选择 Word、正文 HTML、完整 HTML 或网页 PDF。
4. 保持原网页及导出页打开，等待文件生成或 PDF 预览完成。

自动加载会滚动主页面、内部滚动区域和可读取的同源嵌入页面。正常完成或点击停止后恢复原阅读位置；手动点击网页、滚动或使用滚动按键会停止加载并保留当前阅读位置。关闭插件弹窗不会停止加载，再次打开可查看进度。

每次加载约有 2 分钟、600 次滚动、24 个区域及 200000 像素高度的限制；持续增加内容也会触发停止。达到限制时可检查原网页并再次加载，不代表所有内容已经取得。

## 缺失资源

导出页会列出无法保存的图片或字体等资源。点击「读取浏览器已加载资源并继续」时，可授予 `pageCapture` 归档权限；仍缺资源时，点击「补全缺失图片和字体」可对所需网站授权。这些权限都由用户选择。

不授权也可保存已读取内容。权限被拒绝、网站返回错误、资源跨域受限或资源过大时仍可能缺失。单个读取资源上限为 30 MB；资源累计有 150 MB 预算，可能提前停止补全。已授权的网站可在 Chrome 扩展详情中管理。

## PDF 设置

选择网页 PDF 后会打开预览并调用 Chrome 原生打印。目标选择「另存为 PDF」，边距设为「无」，开启「背景图形」，确认预览后保存。若打印窗口被关闭，可以在预览页再次点击打印按钮。预览依赖导出页提供内容，请保留导出页打开。

PDF 按网页宽度生成长页，超长页面会分段；网页中真实文字可选择、搜索，图片内的文字不会自动识别。缺失图片、过大快照或预览过期可能阻止打印，请返回原网页重试。

## 常见问题

| 问题 | 建议 |
| --- | --- |
| 扩展目录无法加载 | 确认选择 `extension` 文件夹，直接包含 `manifest.json`；使用符合最低版本要求的 Chrome |
| 当前页面无法转换 | 切换到普通 HTTP/HTTPS 网页，刷新后点击工具栏图标 |
| 保存按钮不可用 | 等待加载或停止恢复完成；确认原网页仍打开 |
| 正文不完整或识别失败 | 先展开内容并加载，尝试完整 HTML，核对实际输出 |
| 图片、字体缺失 | 检查详情，按需启用资源补全；网站限制可能仍无法解决 |
| Word 与网页不同 | Word 会按纸张宽度重新排版，需保留网页外观时尝试 HTML 或 PDF |
| 提示网页已切换 | 在目标网页重新点击插件，重新开始转换 |

导出私人页面可能保留个人信息与普通表单值。分享前检查文件；反馈时请移除登录信息、内部地址和私人内容。通过 [Issues](https://github.com/utiwaaaaaien/webpage-conversion-helper/issues) 提供版本、格式、Chrome 版本及脱敏复现步骤。
