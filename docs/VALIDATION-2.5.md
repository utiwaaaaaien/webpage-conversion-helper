## 原因和修复

一篇含大量公式、代码和图片的长文有 4,805 个正文元素。V2.4 为每个元素重复保存计算样式，触发 48 MiB 样式限制；注入脚本的异常未能传回转换页面，界面只显示“未能读取页面”。正文 HTML、完整 HTML 和 PDF 共用这条链路。该样本的 Word 导出在 V2.4 中可以完成。

V2.5 复用相同的计算样式，限制按独立样式统计，同时保留嵌套文档自己的样式。转换入口返回明确错误；PDF 替换选择控件时保留样式引用。本次没有新增权限。
