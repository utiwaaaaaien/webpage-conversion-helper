## 读取与处理的信息

用户主动加载或转换网页时，插件读取当前网页的标题、地址、可访问正文、样式和资源，用于生成 Word、HTML 或 PDF。完整页面快照还可能包含普通输入框、文本域和选择框的当前值，因此导出文件可能包含个人或内部信息。密码和文件输入框的 `value` 属性会从快照移除；这一处理并不保证清除网页中其他位置显示的敏感信息。

插件使用浏览器已有的访问权限和登录会话读取可访问资源，代码不通过 Cookie 或身份接口提取、保存登录凭据，也不绕过网站认证。

## 本机处理与网络请求

转换在本机完成。当前代码未设置开发者上传接口、遥测、广告、云端转换或后台浏览历史采集，也不使用扩展存储接口建立持久化网页数据库。

自动滚动会触发网页自身的内容与图片请求。补全图片、字体或样式时，插件会访问资源原地址，请求可能携带浏览器允许的现有会话凭据。资源网站会按自身规则处理地址、网络信息和请求，不应将「本机转换」理解为完全没有网络访问。

运行脚本随安装包提供，不从外部网站下载执行脚本。使用 GitHub 下载、浏览文档或提交 Issue 的行为受 GitHub 自身规则约束。

## 权限与用户控制

点击工具栏图标后，`activeTab` 提供当前网页的临时访问权，`scripting` 用于读取与用户启动的自动加载。`pageCapture` 和具体 HTTP/HTTPS 资源网站访问权为可选权限，通过导出页操作按需请求。已授予的网站权限可能保留，可在 Chrome 扩展详情中管理。

用户可停止自动加载、拒绝资源补全权限、关闭转换页面或卸载扩展。页面和资源在运行期间保存在内存及临时浏览器对象中；转换流程会清理部分临时引用，关闭相关页面或标签页会结束相应页面的处理上下文。

## 导出文件与删除

文件通过浏览器下载或原生打印保存；下载设置可能直接保存到默认目录，也可能询问保存位置。文件保留至用户自行删除。插件不会在卸载时删除已导出的文件。

完整 HTML 保存静态页面，并清理执行脚本、事件处理与表单提交行为。导出仍可能包含个人内容、普通表单值和原网站链接；分享前请检查。主动点击保存文件中的链接将访问目标网站。
