# 网页转换助手 · Webpage Conversion Helper

**将当前网页保存为 Word、正文 HTML、完整 HTML 或 PDF，在本机完成转换。**

[English](README.en.md) · [下载安装包](https://github.com/utiwaaaaaien/webpage-conversion-helper/releases/latest) · [使用指南](docs/USAGE.zh-CN.md) · [隐私说明](docs/PRIVACY.zh-CN.md) · [更新记录](CHANGELOG.md)

适合保存文章、整理研究资料、制作可编辑文档，以及离线阅读已加载的网页。支持自动滚动加载图片和内容，转换时显示缺失资源与加载限制。

当前版本 **2.4.0**，要求 **Chrome 116 或更高版本**。插件界面为**简体中文**；本仓库提供中英文说明。目前通过 GitHub 安装包分发，尚未发布到 Chrome 网上应用店。

## 四种保存方式

| 格式 | 保存内容 | 适用场景 |
| --- | --- | --- |
| Word `.docx` | 识别文章正文，尽量保留图片、标题、表格、列表和文字格式，按纸张分页 | 编辑、批注、整理材料 |
| 正文 HTML | 文章正文、原网页样式和可读取的配图，尽量移除导航、侧栏等组件 | 离线阅读文章 |
| 完整 HTML | 当前已加载页面的静态外观，包括导航、侧栏和页脚 | 保存网页阅读效果 |
| 网页 PDF | 使用 Chrome 原生打印保存网页宽度的长页 PDF；文字内容可选择和搜索 | 阅读、归档、分享 |

Word 会重新排版，不保证与网页逐像素一致。PDF 中原本属于图片的文字仍是图片；超长网页可能分成长页。HTML 保存静态阅读效果，视频主要保留封面，交互与播放需要访问原网页。

## 安装

1. 从 [Releases](https://github.com/utiwaaaaaien/webpage-conversion-helper/releases/latest) 下载 `webpage-conversion-helper-2.4.0-chrome.zip` 并解压。
2. 在 Chrome 地址栏输入 `chrome://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择解压后的 **`extension` 文件夹**，其中应直接包含 `manifest.json`。
4. 将「网页转换助手」固定到工具栏，打开一个普通 HTTP/HTTPS 网页。

解压文件夹是 Chrome 的安装来源，请将其放在固定位置。不要直接加载 ZIP 或选择仓库根目录。也可下载仓库源码，按同样步骤加载其中的 `extension` 文件夹。

更新时先备份原安装目录，用新版本替换原 `extension` 文件夹的内容，再到扩展程序页面点击「重新加载」，并刷新待转换网页。详细步骤见 [使用指南](docs/USAGE.zh-CN.md)。

## 使用

打开网页，先手动展开需要保存的折叠内容。点击插件，可先点击「加载全部网页」触发懒加载，待完成或停止后选择保存格式。自动加载期间关闭弹窗仍会继续运行；再次打开可查看进度。加载中暂停保存。

遇到图片或字体缺失时，导出页会显示详情。你可以选择读取 Chrome 已加载的归档资源，或进一步授权所需资源网站；也可保存已取得的内容。转换期间请保持原网页与导出页打开。

PDF 会打开原生打印窗口。选择「另存为 PDF」、边距「无」，并开启「背景图形」。

## 权限与隐私

| 权限 | 用途 |
| --- | --- |
| `activeTab` | 点击工具栏图标后，临时读取当前网页 |
| `scripting` | 在该网页读取正文、样式、图片，并执行用户启动的加载 |
| `pageCapture`（可选） | 用户授权后读取 Chrome 页面归档，补全浏览器已加载资源 |
| HTTP/HTTPS 网站访问（可选） | 按需申请具体资源来源，补全缺失图片和字体 |

转换在本机处理；代码中未设置开发者上传服务、广告、遥测或后台浏览历史采集。加载与资源补全会向原网页及其资源网站发出请求，可能使用浏览器已有的登录会话。完整网页快照可能包含可见的个人内容与普通表单值，分享前请检查导出文件。详见 [隐私说明](docs/PRIVACY.zh-CN.md)。

## 已知限制

- 只能保存当前可访问、已加载的内容；不会绕过登录、付费墙或网站资源限制。
- 自动加载不会展开折叠内容、自动翻页或恢复已被虚拟列表移除的内容。
- 自动加载单次约 2 分钟、最多 600 次滚动、24 个滚动区域，页面高度上限 200000 像素；持续增高也会触发停止。
- 正文 HTML 与 Word 可通过浏览器归档读取已识别的嵌入正文；归档缺失、多个正文候选或图片尚未加载时会提示。完整 HTML/PDF 中跨域嵌入内容仍可能缺失。
- 受保护画布、无法读取的图片和字体可能缺失；请查看转换提示。
- 正文识别可能失败。可尝试完整 HTML，或检查导出内容。
- Chrome 内部页面、扩展页面及其他受限制页面不适用。其他 Chromium 浏览器尚未单独验证。

## 开发与反馈

源码和依赖随仓库提供，无需构建或在线下载运行脚本。目录与验证步骤见 [贡献指南](CONTRIBUTING.md)。反馈请提交 [Issue](https://github.com/utiwaaaaaien/webpage-conversion-helper/issues)，注明版本、网页类型、导出格式和错误信息，并移除私人内容。

V2.4 修复正文位于嵌入页面时误读外层内容的问题，并统一 Word 与正文 HTML 的识别规则。验证包含实际 KM 导出、文字与图片对照、离线渲染及公开回归用例；其他网站仍需按导出提示检查。
