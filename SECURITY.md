# 安全说明 / Security

请使用当前版本。浏览器端资源读取与导出可能涉及私有网页，分享文件前请检查内容，并仅授予所需的可选网站权限。

Use the current version. Resource retrieval and exports can involve private pages. Inspect files before sharing and grant only the optional site access you need.

如发现可导致脚本执行、跨标签页数据泄露或越权访问的问题，请使用仓库 Security 页面的「Report a vulnerability」进行私密报告。请提供脱敏复现步骤、Chrome 与插件版本、影响及最小示例。不要在公开 Issue 中提交漏洞细节、凭据或私人内容。

For script execution, cross-tab data leakage, or unauthorized access, use **Report a vulnerability** on this repository's Security page to submit a private report. Include sanitized steps, Chrome and extension versions, impact, and a minimal example. Do not post exploit details, credentials, or private content in public issues.

本仓库的静态发布检查不构成完整安全审计，也不承诺响应时限。 / Static publication checks are not a complete security audit. No response deadline is promised.
